확정
  • 기본 기간 `최근 4주`
  • 선택 `4주 / 3개월 / 6개월 / 1년`
  • 상단 지표 `운동 횟수 / 완료 세트 / 운동 시간`
  • 분석 홈은 상세 분석을 모두 펼치는 곳이 아니라 허브
현재 검토안
상단 요약 → 부위별 운동 분포 → 운동 빈도 → 운동별 변화 → 최근 운동 기록 순서.
아직 미정
바디맵 실제 색/레이어 표현, 운동 빈도 차트 방식, `운동별 성장/변화`라는 명칭과 홈에 몇 개를 노출할지.
이동
부위 카드 → 07B / 운동별 변화 → 07C / 전체 운동 기록 → 07D / 최근 기록 행 → 07E.
이 화면을 먼저 보고 “분석 홈이 너무 많은가 / 적당한가”를 판단하면 됩니다. 상세 분석 계산을 여기서 전부 보여주지는 않습니다.

확정

운동 기록 상세의 역할

실제 수행만 표시 확정상단 요약 검토안
확정
실제로 완료/저장된 운동과 세트만 보여준다. 부분 저장이라면 하지 않은 예정 운동을 복원해 보여주지 않는다.
기록 방식
각 운동의 `recording_type`에 맞춰 중량+횟수, 횟수, 시간, 어시스트 중량+횟수 등을 그대로 표시한다.
현재 검토안
세션명/날짜/시간 → 요약 → 실제 수행 운동과 세트 상세.
조건부 지표
`총 볼륨`은 의미 있는 중량 운동이 있을 때만 사용할 수 있으며 모든 운동을 대표하는 고정 지표로 강제하지 않는다.
아직 미정
저장 기록 편집 허용 범위, 메뉴(삭제/공유 등), PR 표시 밀도.

  2. 바디맵을 분석 홈에서 어느 정도 크게 보여줄지 — 상세 07B로 들어가기 전에도 시각적 존재감을 크게 둘지.
  3. 운동 빈도가 별도 상세 화면까지 필요한지 — 아니면 분석 홈 카드 정도면 충분한지.
  4. 운동별 성장 화면의 표현 — 사용자에게 가장 이해하기 쉬운 기록 변화 기준과 명칭.
  5. 운동 기록 목록의 정보량 — 날짜/시간/세트만 둘지, 종목 수·부위·PR까지 더할지.
