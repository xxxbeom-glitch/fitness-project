# UX Planning Locks — 2026-09-02

**Status:** CONFIRMED
**Scope:** G Fit 2차 기획 / 주요 화면 흐름

이 문서는 2026-09-02 대화에서 Product Owner가 승인한 큰 UX 방향만 기록한다. 세부 UI 크기, 문구, 정확한 지표 계산법은 후속 화면 기획에서 조정할 수 있다.

## 1. Home

Home은 사용자가 앱을 열었을 때 가장 먼저 운동을 시작하거나 진행 중인 운동으로 돌아가게 한다.

상태별 최상단 행동:

- 루틴 없음: 추천 루틴 / 내 루틴 만들기
- 루틴 있음 + 요일 미지정: 다음 운동
- 루틴 있음 + 요일 지정: 오늘의 운동
- 진행 중 운동 있음: 운동 계속하기

상세 그래프와 깊은 분석은 Home의 주 역할이 아니다.

## 2. Active Workout

운동 기록 화면은 전체 운동을 한 화면에서 이어서 보고, 현재 운동만 펼쳐서 기록하는 방식을 기본으로 한다.

기본 원칙:

- 현재 운동은 펼쳐서 세트 / 이전 기록 / kg / 횟수 / 완료를 한곳에 표시
- 다음 운동은 아래에 접어서 표시
- 이전 기록은 입력 영역 가까이에 둠
- 휴식 타이머는 화면을 가리지 않는 작은 형태로 표시
- 운동 하나마다 별도 화면처럼 넘기는 구조는 기본값으로 쓰지 않음

## 3. Recommended Routine Save Flow

추천 루틴은 시작한다고 자동 저장하지 않는다.

기본 흐름:

1. 추천 루틴 내용을 본다.
2. 저장 없이 바로 운동을 시작할 수 있다.
3. 오늘 운동 기록은 항상 저장된다.
4. 운동이 끝난 뒤 사용자가 내 루틴에 저장할지 결정한다.

운동 중 구성을 바꿨다면 오늘 운동 기록은 실제 수행 내용 그대로 남긴다. 루틴 저장 버튼을 누른 뒤에만 오늘 한 구성으로 저장할지, 원래 추천 구성으로 저장할지 추가로 묻는다.

즉 평소 완료 화면에서는 선택을 단순하게 유지하고, 구성 변경이 있을 때만 추가 선택을 보여준다.

## 4. Post-workout Completion

운동 완료 화면은 단순 완료 메시지만 보여주지 않는다. 오늘 운동을 풍부하게 돌아볼 수 있게 한다.

승인된 큰 구조:

- 상단 카드 캐러셀
  - 1장: 오늘 운동 요약
  - 2장: 오늘 좋아진 기록
  - 3장: 이번 주 기록
- 그 아래: 오늘 실제 운동 결과 전체
- 추천 루틴으로 운동한 경우에만: 내 루틴 저장 / 이번만 하기

역할 구분:

- 운동 완료 화면: 오늘 운동을 여러 각도로 짧게 확인
- 분석 탭: 월별 추세, 장기 그래프, 종목별 세부 변화 등 긴 기간 분석

정확한 지표, 계산법, 카드 순서, 문구는 후속 완료 화면 기획에서 확정한다.
