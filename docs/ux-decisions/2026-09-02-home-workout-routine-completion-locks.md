# UX Planning Locks — 2026-09-02

**Status:** CONFIRMED
**Scope:** G Fit 2차 기획 / 주요 화면 흐름

이 문서는 2026-09-02 대화에서 Product Owner가 승인한 큰 UX 방향만 기록한다. 세부 UI 크기, 문구, 정확한 지표 계산법은 후속 화면 기획에서 조정할 수 있다.

## 1. Home

Home은 사용자가 앱을 열었을 때 가장 먼저 운동을 시작하거나 진행 중인 운동으로 돌아가게 한다.

상태별 최상단 행동:

- 루틴 없음: 추천 루틴 / 내 루틴 만들기
- 루틴 있음 + 요일 미지정: 다음 운동
- 루틴 있음 + 요일 지정: 오늘의 운동
- 진행 중 운동 있음: 운동 계속하기

상세 그래프와 깊은 분석은 Home의 주 역할이 아니다.

## 2. Active Workout

운동 기록 화면은 전체 운동을 한 화면에서 이어서 보고, 현재 운동만 펼쳐서 기록하는 방식을 기본으로 한다.

기본 원칙:

- 현재 운동은 펼쳐서 세트 / 이전 기록 / kg / 횟수 / 완료를 한곳에 표시
- 다음 운동은 아래에 접어서 표시
- 이전 기록은 입력 영역 가까이에 둠
- 휴식 타이머는 화면을 가리지 않는 작은 형태로 표시
- 운동 하나마다 별도 화면처럼 넘기는 구조는 기본값으로 쓰지 않음

## 3. Recommended Routine Save Flow

추천 루틴은 시작한다고 자동 저장하지 않는다.

기본 흐름:

1. 추천 루틴 내용을 본다.
2. 저장 없이 바로 운동을 시작할 수 있다.
3. 오늘 운동 기록은 항상 저장된다.
4. 운동이 끝난 뒤 사용자가 내 루틴에 저장할지 결정한다.

운동 중 구성을 바꿨다면 오늘 운동 기록은 실제 수행 내용 그대로 남긴다. 루틴 저장 버튼을 누른 뒤에만 오늘 한 구성으로 저장할지, 원래 추천 구성으로 저장할지 추가로 묻는다.

즉 평소 완료 화면에서는 선택을 단순하게 유지하고, 구성 변경이 있을 때만 추가 선택을 보여준다.

## 4. Post-workout Completion

운동 완료 화면은 단순 완료 메시지만 보여주지 않는다. 오늘 운동을 풍부하게 돌아볼 수 있게 한다.

승인된 큰 구조:

- 상단 카드 캐러셀
  - 1장: 오늘 운동 요약
  - 2장: 오늘 좋아진 기록
  - 3장: 이번 주 기록
- 그 아래: 오늘 실제 운동 결과 전체
- 추천 루틴으로 운동한 경우에만: 내 루틴 저장 / 이번만 하기

역할 구분:

- 운동 완료 화면: 오늘 운동을 여러 각도로 짧게 확인
- 분석 탭: 월별 추세, 장기 그래프, 종목별 세부 변화 등 긴 기간 분석

정확한 지표, 계산법, 카드 순서, 문구는 후속 완료 화면 기획에서 확정한다.

## 5. Exercise Search / Add

운동 추가는 **검색 중심 + 목록에서 바로 추가**를 기본으로 한다.

승인된 큰 구조:

- 루틴 만들기와 운동 중 운동 추가에서 같은 운동 선택 흐름을 재사용
- 화면 진입 시 검색을 가장 먼저 제공
- 검색 결과 목록에서 별도 상세 화면을 거치지 않고 바로 `추가` 가능
- 목록에는 운동명, 장비, 주요 부위, 운동 이미지, 최근 기록을 우선 표시
- 부위 / 장비 필터는 빠른 보조 수단으로 제공
- 운동 이름이나 이미지를 눌렀을 때만 운동 상세 화면으로 이동
- 운동 상세는 이미지, 방법, 체크 포인트, 최근 기록 등을 확인하는 선택 단계이며 운동 추가의 필수 단계가 아님
- 찾는 운동이 없으면 `직접 만들기`로 연결
- 직접 만든 운동도 일반 운동과 동일하게 기록과 이력을 가질 수 있어야 함

Custom exercise의 기본 구조는 기존 DEC-003 / DEC-012를 유지한다.

- 운동 이름
- 장비
- 주요 부위
- 기록 방식
- 보조 부위는 필요할 때 선택적으로 추가 가능

## 6. Exercise Identity / Grip History

운동 기록은 **실제로 비교 가능한 수행끼리만 같은 기록으로 묶는다.**

### 장비가 다르면 별도 기록

같은 동작 계열이어도 장비 방식이 달라 중량 의미와 수행 조건이 달라지면 별도 운동 기록으로 관리한다.

예:

- 바벨 벤치프레스
- 덤벨 벤치프레스
- 스미스 벤치프레스
- 체스트 프레스 머신
- 케이블 프레스

위 운동들은 서로 이전 중량 / 횟수 / PR을 섞지 않는다.

### 그립 기록은 선택 기능

그립 선택은 운동 기록의 필수 입력이 아니다.

사용자가 그립을 따로 관리할 필요가 없다면 `랫풀다운` 같은 기본 운동 기록만으로 운동을 시작하고 완료할 수 있어야 한다. 그립을 선택하지 않았다는 이유로 기록 흐름을 막거나 추가 입력을 요구하지 않는다.

그립별 기록이 필요한 사용자만 운동 카드 안에서 대표 그립을 선택해 별도 이력을 사용한다.

- 그립 미선택 → 기본 운동 이력에 기록
- 대표 그립 선택 → 선택한 그립 이력에 기록
- 기본 운동 이력과 각 그립 이력의 kg / 횟수 / PR은 서로 섞지 않음
- 기존 기본 운동 기록을 나중에 특정 그립 기록으로 자동 재분류하지 않음

### 대표 그립은 한 운동 안의 기록 변형으로 관리

검색 목록을 그립별 운동명으로 늘리지 않는다.

예를 들어 기본 검색 결과에는 `랫풀다운` 하나를 보여준다. 그립별 기록을 쓰는 사용자는 **같은 운동 카드 안에서 오버핸드 / 뉴트럴 같은 대표 그립 기록을 선택하거나 전환**한다.

그립을 바꾸면 다음 데이터가 함께 전환된다.

- 해당 그립의 최근 기록
- 이전 kg / 횟수
- 그립별 PR
- 세트 입력의 기본 참고값
- 오늘 기록이 저장될 그립 이력

화면에서는 하나의 `랫풀다운` 운동이지만, 내부적으로는 기본 운동 기록과 대표 그립별 수행 기록을 섞지 않는다.

### 모든 손 위치를 그립 변형으로 만들지는 않음

앱이 제공하는 그립 변형은 반복해서 별도로 추적할 가치가 있는 **대표 그립**만 둔다.

손 너비를 조금 바꾸거나 시트 / 손잡이 위치를 미세 조정한 정도는 새 기록 변형을 만들지 않고 같은 운동 / 같은 그립 기록에 메모나 세팅 정보로 남긴다.

### 현재 확정 범위 밖

- 어떤 운동에 어떤 대표 그립을 제공할지의 전체 목록
- 그립 선택 UI의 정확한 형태와 마지막 선택 기억 여부
- 브랜드 머신 / 모델별 기록 identity
- 그립별 장기 분석을 MVP 첫 화면에서 어디까지 노출할지
- 작은 세팅 차이를 구조화된 metadata로 저장할지 단순 메모로 둘지

## Next

다음 큰 기획 범위는 **구매 DB 정규화**다.

MVP 기본 운동 DB에서는 제조사 / 브랜드별 머신 목록을 별도로 운영하지 않는다. 특정 브랜드/모델 머신 기록이 꼭 필요한 사용자는 `직접 만든 운동`으로 별도 기록할 수 있게 두고, 제조사 DB 확장은 실제 수요가 확인된 뒤 재검토한다.

다음으로 정할 것:

- 구매한 운동 DB의 영문/해외 명칭을 국내 대표 이름으로 어떻게 정리할지
- 이름만 다른 실제 중복 운동을 어떤 규칙으로 합칠지
- 실제 구매 metadata 전체를 `유지 / 이름 변경 / 중복 통합 / 별도 유지 / 1차 제외`로 분류할 기준
