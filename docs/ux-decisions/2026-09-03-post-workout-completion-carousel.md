# Post-workout completion carousel / export UX

**Status:** PO APPROVED — content / interaction direction approved, including routine trend graph + next workout hint and completion card content-density constraint; exact visual copy and production implementation pending

**Date:** 2026-09-03

## Decision

운동 완료 화면은 오늘 운동을 짧게 복기할 수 있는 **카드 캐러셀**을 중심으로 구성한다.

Hevy의 `완료 후 여러 장의 요약 카드를 넘겨보는 패턴`은 레퍼런스로만 사용한다. **카피, 카드 내용 조합, 비교 대상, 시각 구성은 G Fit용으로 별도 설계**하며 그대로 복제하지 않는다.

## Completion card layout constraint — PO APPROVED

완료 캐러셀의 각 카드는 향후 디자인 단계에서 **가로:세로 = 1:1.25** 비율을 기본 기준으로 잡는다.

핵심은 단순히 데이터를 많이 넣는 것이 아니라, **한 장 안에서 제목 / 핵심 시각화 / 핵심 수치 / 짧은 설명이 균형 있게 읽히는 데이터 양으로 제한**하는 것이다.

- 카드 높이를 넘겨 내부 스크롤이 생기는 구성을 기본으로 사용하지 않는다.
- 한 카드에서 모든 세부 근거를 다 보여주려 하지 않는다.
- 상세 설명이나 긴 목록은 별도 상세 화면 / 분석 영역 / 후속 진입으로 넘길 수 있다.
- 카드마다 시각적 중심 하나를 우선한다. 예: 큰 수치, 그래프, 해부학 아바타, 운동 목록 등.
- 보조 수치는 핵심 시각화를 방해하지 않는 수준으로 제한한다.
- 긴 운동 목록, 너무 많은 그래프 선, 세부 출처 운동 목록 등은 1:1.25 카드 안의 균형을 깨면 축약하거나 별도 상세로 분리한다.
- wireframe review에서는 정보 구조를 확인하되, 최종 밀도 / 여백 / 타이포 / 시각적 균형은 Figma 디자인 단계에서 확정한다.

즉, 완료 카드 설계의 공통 기준은 **“한 장에서 바로 이해되는 정보량”**이다.

### Carousel content direction

기본 카드 후보는 다음과 같다.

1. **오늘 기록 요약**
   - 운동 시간
   - 총 볼륨
   - 완료 세트
   - 완료 운동 수

2. **총 볼륨 비유**
   - 오늘 들어 올린 총 볼륨을 동물 / 탈것 / 사물 등 이해하기 쉬운 무게 대상으로 환산
   - 재미 요소이며 운동 성과의 단일 평가 기준으로 사용하지 않음
   - 비교 대상 목록과 기준 무게는 G Fit 자체 데이터로 별도 정의

3. **오늘의 발전**
   - 새 최고 기록 또는 지난 같은 운동보다 의미 있게 좋아진 변화
   - 동일 중량 반복 증가, 최고 중량 등
   - 의미 있는 변화가 없으면 카드 생략 가능
   - `assisted_weight_reps` 운동은 일반 중량 운동처럼 `더 높은 kg = 더 좋은 기록`으로 해석하지 않음

4. **최근 루틴 흐름 + 다음 운동 힌트** — 조건부 · **PO APPROVED**
   - 단순히 `증량해보세요` 문장만 보여주지 않고, **해당 루틴의 최근 변화 그래프와 함께 힌트를 설명**한다.
   - 그래프에는 루틴 전체 흐름과 루틴에 포함된 각 운동의 흐름을 여러 개의 꺾은선으로 겹쳐 보여주는 방향을 사용한다.
   - 루틴 전체의 현재 총 수치는 별도로 보여주고, 운동별 현재 수치 / 상태도 범례나 보조 정보로 확인할 수 있게 한다.
   - 루틴 전체 볼륨과 개별 운동 볼륨은 절대값 크기가 크게 다를 수 있으므로, **같은 Y축에 kg 절대값을 그대로 섞어 비교하지 않는 방향**을 기본으로 한다.
   - review 단계에서는 각 항목의 첫 기록을 100으로 맞춰 상대 변화 흐름을 겹쳐 보는 방식을 후보로 사용한다. 실제 제품 지표는 별도 확정한다.
   - 그래프에서 특정 운동의 흐름이 정체되어 있고, 해당 운동이 목표 반복 범위를 안정적으로 수행하는 등 증량 조건을 만족할 때 그 아래에 `다음 운동에서 중량을 조금 올려볼 만해요` 같은 힌트를 제공한다.
   - 모든 운동을 같은 날짜 / 같은 주차 기준으로 판단하지 않고 **운동별 실제 수행 기록을 따로 관찰**한다.
   - 사용자가 앱 추천 전에 이미 해당 운동 중량을 올렸다면 뒤늦게 같은 증량 메시지를 띄우지 않고 새 중량을 새로운 기준으로 다시 관찰한다.
   - 세트 수 변경, 일시적 감량 이유, 컨디션까지 MVP에서 모두 해석하지 않는다.
   - `assisted_weight_reps`는 일반 중량 증가가 아니라 **보조 중량 감소 방향**의 별도 규칙이 필요하므로 일반 증량 로직에서 제외한다.
   - 충분한 루틴 이력이나 추천 후보가 없으면 이 카드는 생략할 수 있다.
   - 운동 수가 많아 그래프 선이 과밀해지면 1:1.25 카드 균형을 우선하고, 대표선 / 선택 / 축약 등으로 정보량을 줄인다.

5. **오늘 운동 부위**
   - 실제 완료 세트 기반 분포
   - 사용자의 실제 근육 자극 비율을 추정하거나 과장하지 않음
   - 향후 해부학 아바타 시각화와 연결 가능
   - 1:1.25 카드 안에서는 `해부학 시각화 + 핵심 부위 수치`를 우선하고, 운동별 세부 산출 근거를 전부 노출하지 않는다.

6. **오늘 한 운동 / 실제 수행 결과**
   - 기존에 캐러셀 아래 길게 두던 `오늘 운동 결과`를 별도 목록으로 반복하지 않고 **캐러셀 카드 안으로 통합**
   - 운동명 / 손잡이(해당 시) / 완료 세트 / kg·횟수 등 실제 기록을 표시
   - 미완료 운동은 완료 결과로 채우지 않음
   - 운동 수가 많아 1:1.25 카드에 균형 있게 들어오지 않으면 축약 표시 후 상세 진입 방식 등을 별도 검토한다.

7. **최근 흐름** — 조건부
   - 이번 주 운동 횟수, 의미 있는 연속 기록 등 지금 보여줄 가치가 있을 때만 등장
   - 월별 장기 추세 / 깊은 종목 분석은 Analysis 영역에 남김

카드 수는 반드시 고정하지 않는다. 해당 세션에서 의미 없는 카드는 생략할 수 있다.

## Export / share direction

캐러셀 아래에는 별도 긴 운동 결과 목록 대신 **내보내기 행동**을 배치한다.

기본 후보:

- 사진 저장
- 스토리 공유
- 카카오톡 보내기
- 더보기 / 시스템 공유

기본 동작 원칙은 **현재 사용자가 보고 있는 카드가 내보내기 대상**이 되는 것이다.

- 사진 저장: 현재 카드의 공유용 이미지 저장
- 스토리 공유: 현재 카드 내용을 세로형 스토리 포맷으로 내보내는 방향
- 카카오톡: 현재 카드 이미지를 카카오톡 공유 대상으로 전달하는 방향
- 더보기: OS 시스템 공유 시트 등 기타 공유 수단

정확한 플랫폼별 포맷, 비율, 공유 API, 텍스트 동봉 여부는 구현 단계에서 확정한다.

## Recommended routine exception

추천 루틴으로 시작한 운동이라면 기존 결정대로 운동 완료 후 `내 루틴으로 저장` 여부를 별도로 선택할 수 있다.

이 선택은 일반 완료 캐러셀의 핵심 콘텐츠가 아니며 **해당 세션에서만 조건부로 추가**한다.

## Review artifacts

- `product/wireframe/completion-review.html`
- `product/wireframe/progression-hint-review.html`

`progression-hint-review.html`의 **루틴 전체 + 운동별 꺾은선 흐름을 함께 보고, 그 맥락에서 다음 운동 힌트를 주는 구조**는 PO 승인되었다.

현재 review artifact는 승인된 방향을 확인하기 위한 preview이며 canonical production wireframe 승격은 별도 결정 전까지 하지 않는다.

## Deferred

- 카드별 정확한 카피
- 1:1.25 카드의 실제 px size / 내부 여백 / typography scale
- 총 볼륨 비교 대상 catalog / 기준 무게 / 환산 반올림 규칙
- `오늘의 발전` 선정 우선순위와 동률 처리
- `최근 루틴 흐름` 그래프의 정확한 기준 지표: 볼륨 / 최고 수행중량 / 운동별 종합 변화값 / 상대 변화율
- 그래프에 몇 회의 과거 기록을 기본 노출할지
- 운동이 많은 루틴에서 그래프 선을 몇 개까지 동시에 표시할지, 선택/필터 UX
- `다음 운동 힌트`의 정확한 운동 분류 / 관찰 횟수 / 반복 범위 / 추천 임계값
- assisted / bodyweight / duration 계열의 별도 progression 규칙
- 운동 부위 세트 배분 세부 규칙
- 긴 운동 목록이 한 카드 높이를 초과할 때의 상세 표시 방식
- 스토리 / 카카오톡 / 시스템 공유의 실제 네이티브 구현 방식
- 공유 이미지 브랜딩 / 워터마크 여부
