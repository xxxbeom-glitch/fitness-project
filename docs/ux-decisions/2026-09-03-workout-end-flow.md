# Workout End Flow — 2026-09-03

**Status:** PO APPROVED
**Scope:** Active Workout 종료 확인과 미완료 세트가 있을 때의 조기 종료

## Decision

운동은 모든 세트를 완료해야만 종료할 수 있는 구조가 아니다.

사용자는 언제든지 `운동 종료`를 눌러 현재 세션을 끝낼 수 있다. 다만 종료 시점의 상태에 따라 확인 문구를 다르게 보여준다.

## 1. 모든 예정 세트가 완료된 경우

모든 예정 세트가 완료되더라도 자동으로 운동을 종료하지 않는다.

사용자가 `운동 종료`를 누르면 한 번 확인한다.

권장 의미:

> 모든 세트를 완료했습니다. 운동을 종료할까요?

행동:

- `계속 운동`
- `운동 종료`

사용자가 `운동 종료`를 선택하면 오늘 완료한 기록을 저장하고 다음 종료 후 흐름으로 진행한다.

## 2. 완료하지 않은 세트 / 운동이 남아 있는 경우

사용자는 일부 세트나 운동을 끝내지 않았어도 언제든지 운동을 종료할 수 있다.

`운동 종료`를 누르면 미완료 상태임을 알려주고 한 번 확인한다.

권장 의미:

> 아직 완료하지 않은 운동이 있습니다. 지금 종료하면 완료한 세트까지만 기록됩니다.

행동:

- `계속 운동`
- `종료하고 저장`

종료를 선택하면 **실제로 완료 체크된 세트만 오늘 운동 기록으로 저장**한다.

미완료 운동 / 미완료 세트는 완료된 것처럼 기록하지 않는다.

미수행했다는 이유만으로 저장된 루틴에서 자동 삭제하지 않는다.

## 3. 루틴 구조 변경이 있었던 경우

운동 종료 확인 이후, 오늘 세션에서 루틴 구조 변경이 있었다면 기존 승인 정책에 따라 한 번만 추가 확인한다.

예:

`운동 추가 2개 · 운동 삭제 1개 · 세트 추가 1개`

선택:

- `오늘만 적용`
- `루틴 업데이트`

오늘 운동 기록은 어느 쪽을 선택해도 보존한다.

실제 수행 순서, 미수행 운동, kg / 횟수 변경은 루틴 구조 변경으로 보지 않는다.

기준 문서:

`docs/ux-decisions/2026-09-03-active-workout-routine-update.md`

## 4. Figma mapping

기존 Figma의 종료 modal shell은 재사용할 수 있다.

- `403a_Workout_End_Incomplete` → 미완료 세트 / 운동이 남은 조기 종료 확인
- `403b_Workout_End_Complete` → 모든 예정 세트 완료 후 종료 확인
- `403c_Workout_Save_Or_Discard` → 일반 종료의 `저장하지 않기` 화면으로 사용하지 않는다. 루틴 구조 변경 확인으로 repurpose하거나, 전체 운동 기록 폐기 edge case를 별도 흐름으로 분리한다.

## 5. Explicit non-goals

- 모든 세트 완료 시 자동 종료하지 않음
- 미완료 세트가 있으면 종료 자체를 막지 않음
- 일반 종료 흐름에서 `저장하지 않기`를 기본 선택지로 제공하지 않음
- 운동 완료 여부 때문에 루틴을 자동 수정하지 않음

## Deferred

- 전체 운동 기록을 통째로 폐기하는 별도 진입점과 확인 카피
- 종료 확인 modal의 최종 디자인 / 문구 미세 조정

## Implementation

Cursor 제품 구현은 아직 승인하지 않는다.
