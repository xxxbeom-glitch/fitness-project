- description: `삭제한 운동 기록은 되돌릴 수 없어요.`

- after success, return to the previous valid parent destination; if the previous state itself depends on the now-deleted session, use Home as the safe fallback rather than returning to an invalid detail/completion state

No delete action occurs on merely tapping the trash icon; confirmation is required.
