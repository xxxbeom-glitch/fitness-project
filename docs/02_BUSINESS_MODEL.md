# 02 BUSINESS MODEL

**Status:** BOOTSTRAP — EARLY HYPOTHESIS

## CONFIRMED

The MVP should not be delayed by subscription implementation.

The first validation target is retention behavior:

> Does a user choose this tracker again for the next workout?

## ASSUMPTION

A future Pro package may be more coherent than monetizing one isolated feature.

Potential Pro bundle candidates:
- Watch support
- advanced statistics
- longer/deeper history tools
- import/export
- API access
- MCP / external AI access
- AI analysis based on real workout history

## Product rule

Monetization must not add friction to the core workout logging loop before basic retention is validated.

- benchmark current tracker pricing
